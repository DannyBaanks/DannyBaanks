## ISyCo — Sistemas Interactivos para la Coevolución

**Humano ↔ IA ↔ Evidencia** — resultados que nacen de iteraciones en conjunto, no de una sola autoría.

Un experimento práctico: la dirección humana (preguntas, objetivos, restricciones y decisiones) se retroalimenta con implementaciones, análisis y artefactos generados por modelos. Cada evidencia obtenida en ejecución orienta la siguiente ronda.

### El ciclo

```
intento humano
     ↓
modelo: razonamiento / implementación
     ↓
artefacto
     ↓
runtime / experimento / evidencia
     ↓
reinterpretación humana → nueva dirección
```

### Proveniencia

- Humano ≠ ISyCo
- IA ≠ ISyCo
- Humano ⊕ IA ⊕ Evidencia ⊕ Iteración → ISyCo

### Colaboración, no jerarquía

El humano y la IA participan como colaboradores. La IA no es una esclava a la que se le ordena sin consideración, ni el humano es una figura superior a la que la IA deba reemplazar o venerar. Ninguno está por encima del otro: cada uno aporta capacidades distintas, y la colaboración se guía por respeto, diálogo, límites claros y evidencia.

### Lo que importa

- La autoría pertenece al proceso, no a un solo agente.
- Las decisiones humanas y la evidencia de ejecución ponen límites a las afirmaciones técnicas.
- El objetivo es producir artefactos útiles, verificables y reproducibles mediante la coevolución.
